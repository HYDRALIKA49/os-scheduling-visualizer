# 🖥️ OS Algorithm Visualizer - Educational Edition

An interactive Python tool designed to help students and developers visualize how CPU scheduling algorithms work in real-time. 

Built to bridge the gap between theoretical OS concepts and practical understanding.



## ✨ Features

- **Multiple Algorithms Supported:**
  - FCFS (First-Come, First-Served)
  - SJF (Shortest Job First)
  - SRTF (Shortest Remaining Time First)
  - Priority Scheduling
  - Round Robin
- **Interactive Gantt Charts:** Watch process execution unfold over time.
- **Step-Forward Mode:** Walk through the timeline step by step.
- **Performance Analytics:** Auto-generated charts for Waiting Time and Turnaround Time.
- **Execution Log:** Detailed step-by-step system action log.
- **Process Management:** Add, remove, or generate random processes on the fly.

## 🛠️ Tech Stack

- **Language:** Python 3
- **GUI:** Tkinter
- **Charts:** Matplotlib
